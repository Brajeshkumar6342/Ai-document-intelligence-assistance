# AI Document Intelligence Assistant (Local, Free RAG Pipeline)

A RAG (Retrieval-Augmented Generation) system that answers questions about
your documents — running entirely on your machine, no API keys or cost.

## Stack
- **Embeddings**: `sentence-transformers` (`all-MiniLM-L6-v2`) via HuggingFace
- **Vector store**: Chroma (local, persisted to disk)
- **LLM**: Ollama (`llama3` or `phi3`, running locally)
- **Orchestration**: LangChain

## 1. Install Ollama (the local LLM runner)

Download and install from https://ollama.com (Windows/Mac/Linux all supported).

Then pull a model:

```bash
ollama pull llama3
```

If your laptop is low on RAM (under 16GB), use the smaller, faster model instead:

```bash
ollama pull phi3
```

...and change `LLM_MODEL = "llama3"` to `LLM_MODEL = "phi3"` in `rag_assistant.py`.

Ollama runs a background server automatically after install — verify with:

```bash
ollama list
```

## 2. Install Python dependencies

```bash
cd rag_assistant
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 3. Add documents to index

Drop a few `.pdf` or `.txt` files into `sample_docs/`. (A couple of PDFs — your
own notes, a company handbook, whatever — work well for a demo.)

## 4. Build the index (run once per document set)

```bash
python rag_assistant.py ingest
```

This will:
1. Load every PDF/TXT in `sample_docs/`
2. Split them into ~500-character overlapping chunks
3. Generate embeddings for each chunk
4. Store them in a local Chroma vector database (`chroma_db/`)

## 5. Ask questions

```bash
python rag_assistant.py ask "What is the main topic of this document?"
```

You'll get an answer generated by the local LLM, grounded in the retrieved
chunks, plus the source chunks it used (for citation/traceability).

## 6. (Optional) Run it as a web app instead of the CLI

This project also ships a REST API and a browser UI on top of the same
pipeline, for a point-and-click demo instead of the terminal.

**Terminal 1 — start the API:**
```bash
uvicorn api:app --reload
```
Interactive API docs (Swagger UI) available at http://localhost:8000/docs

**Terminal 2 — start the UI:**
```bash
streamlit run app.py
```
Opens a browser page at http://localhost:8501 with a question box, answer
display, sources, and a button to re-ingest documents without touching the
terminal.

## How it works

1. Documents in `sample_docs/` are loaded and split into ~500-character
   overlapping chunks (so a fact isn't lost if it falls across a chunk
   boundary).
2. Each chunk is embedded with `all-MiniLM-L6-v2` and stored in a local
   Chroma vector database.
3. A question is embedded the same way, and the most similar chunks are
   retrieved via cosine similarity search.
4. The retrieved chunks are inserted into a prompt and sent to a local LLM
   (via Ollama) with an explicit instruction to answer only from that
   context — reducing hallucination and keeping answers traceable to a
   source.

## Known limitations

- Fixed-size chunking can split a sentence or idea mid-way; semantic or
  structure-aware chunking would improve this.
- No re-ranking step after retrieval yet — results are ranked purely by
  embedding similarity.
